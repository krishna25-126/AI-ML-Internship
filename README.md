# AI/ML Internship – Task 1: Environment Setup, Python Foundations & Data Exploration

Internship project for **Sumerix Global** (AI/ML domain).

## Project Overview
This repository covers Task 1: setting up a professional AI/ML environment, learning Python fundamentals, and performing exploratory data analysis (EDA) with Pandas, Matplotlib, and Seaborn.

## Mini Project: Student Performance Data Explorer
Analyzes student performance data to find patterns and trends.

**Workflow:** Load → Clean → Analyze → Visualize → Insights

**Features**
- Data loading and inspection
- Missing value analysis and handling
- Duplicate removal and column renaming
- Statistical summary (mean, median, mode, std)
- Histograms, box plots, scatter plot, correlation heatmap
- Insights report
